## About

I'm a CSE–Data Science student interested in the engineering behind useful AI products: dependable backend APIs, data systems, and retrieval-based applications.

- 🧩 **Core practice:** Data Structures & Algorithms in Java
- ☕ **Backend path:** Java, Spring Boot, REST APIs and SQL
- 🗃️ **Data path:** PostgreSQL, database design and data workflows
- 🤖 **AI path:** LLM applications, RAG, embeddings and retrieval evaluation
- 🎯 **Long-term direction:** AI + Data Engineering, progressing toward Agentic AI systems

> My focus is to turn what I learn into software that can be explained, tested, and improved.
