## 🧠 About Me

I’m a CSE–Data Science undergraduate interested in the engineering behind useful AI products: dependable APIs, structured data, retrieval systems, and intelligent agents.

My goal is not just to call LLM APIs — it is to build systems that can retrieve the right context, use tools safely, explain their actions, and remain reliable in real applications.

- 🤖 **AI/ML:** Python, NumPy, pandas, scikit-learn, PyTorch, LLMs, RAG  
- ☕ **Backend:** Java, Spring Boot, REST APIs, PostgreSQL  
- 🗃️ **Data:** SQL, database design, data pipelines, pgvector  
- 🐳 **Engineering:** Git, Docker, Docker Compose, testing, documentation  
- 🎯 **Long-term goal:** AI + Data Engineering → Agentic AI Engineer  

> I focus on turning what I learn into software that can be explained, tested, improved, and deployed.
